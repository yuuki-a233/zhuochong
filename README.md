## 开始使用

解压下载包，将 `YuukiDesktopPet.exe` 放在你准备长期保留的文件夹，然后双击运行。程序无需安装额外运行库。

- 拖动：拖到哪里就停在哪里，支持在显示器之间拖动；不会吸回底边。
- 点击头部：摸头反应；点击身体：打招呼；双击：读书待机。
- 右键：调整大小、切换活动、打开番茄钟和设置、隐藏或退出。
- 托盘图标：可以找回隐藏的桌宠并打开菜单。

## 已确认的功能

- 日常自动动作加入伸懒腰、揉眼打哈欠、整理头发、左右张望、坐着晃脚、托腮发呆，和打招呼、读书、瞌睡一起打乱轮播，每轮覆盖九种且相邻不重复。互动后约三分之一概率追加拍手或小跳，两种交替出现；右键“动作”可逐个播放八个新动作。眨眼与轻微呼吸动作保持可见。偶尔在放置位置附近散步，保持原高度，并限制在附近约 100 像素范围。摸头和吃文件仍由互动触发。右键可分别开关“自动变换姿势”和“在附近偶尔散步”。开启自动姿势时，手动读书与瞌睡结束后也会继续自动活动。
- 好感度初始 20，范围 0–100；摸头 +1（至少间隔 30 秒），完成一次专注 +2；每天最多增加 10。不同阶段改变摸头表情和短句。离线不扣分。
- 番茄钟默认专注 25 分钟、休息 5 分钟，可以修改；支持暂停、继续、结束。每轮手动开始，关闭计时面板不结束计时，退出程序会结束计时。
- 休息提醒默认 45 分钟；可设置为 5–180 分钟或关闭。专注中不会重复提醒。
- 开机启动开关默认关闭；只在你开启时写入当前用户的 Windows 启动项。移动或删除程序前，请先关闭该开关。
- 安静模式关闭对白和主动提醒，保留动画与手动互动。没有语音。

## 吃文件

将本地普通文件拖到桌宠身上，确认框会列出完整文件路径。选择“送入回收站”后，程序调用 Windows 的专用回收接口；收到成功结果后才播放吃文件动画。取消不会移动文件。

每次最多 100 个文件；当前不接受文件夹、系统文件、链接或网络位置。若系统不支持回收、文件被占用或操作失败，会提示结果；程序没有永久删除的替代路径。右键“打开回收站”可以找回成功回收的文件。

## 本地数据

大小、位置、时间设置和好感度保存在 `%LOCALAPPDATA%\YuukiDesktopPet\settings.ini`。程序不连接聊天模型或上传文件内容。

## 从源码构建

- Windows：使用 CMake 和 Visual Studio，构建 `CMakeLists.txt`。
- Linux：安装 MinGW-w64 后运行 `bash tools/build.sh`；也可通过 `MINGW_BIN` 指定工具链目录。
- `assets/atlas.png` 和图标已经包含，不需要重新生成角色图片。`tools/assemble_assets.py` 用于从生成条带提取和对齐素材，依赖 Pillow 和 NumPy。
- 逻辑检查：`g++ -std=c++17 tests/core_test.cpp -o core_test && ./core_test`。
